## 👨‍💻 About Me

I'm a **AI Engineer** passionate about building modern web applications and autonomous AI agents that turn complex workflows into intuitive, high-performance solutions.

- 💻 **Modern Web Development:** Full-stack development with **Next.js (App Router)**, **TypeScript**, **TailwindCSS**, **FastAPI**, and **PostgreSQL**.
- 🔭 **Currently Building:** Production-ready autonomous agent systems using the **OpenAI Agent SDK** & **Claude Agent SDK**, integrated seamlessly with **Next.js** and cloud infrastructure.
- 🤖 **Agentic Architecture:** Crafting Digital FTEs, multi-agent orchestrations, MCP (Model Context Protocol) servers, and agent factory workflows.
- 💬 **Ask me about:** Agentic Workflows, LLM Function Calling, Next.js Architectures, Prompt Engineering & Python APIs.
- 💼 **Open to:** High-impact AI Engineering roles, collaborative open-source projects, and freelance AI agent development.
